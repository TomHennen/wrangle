## wrangle v0.4.2

The tools wrangle runs in your pipeline are rebuilt on patched dependencies, and Go builds on Go 1.27 no longer crash in the vulnerability check. Pin the reusable workflows at `@v0.4.2`.

**Self-hosted runners:** this release needs Actions runner **2.336.0 or newer**. GitHub-hosted runners work as-is.

### Your pipeline runs on patched tools

- **Go 1.27.4** for every wrangle-built tool.
- **Patched libraries**, including `x/net`, `x/crypto`, `go-jose`, `go-chi`, and OpenTelemetry, each moved to a release that fixes published advisories. wrangle's own scan of its tools went from fourteen findings to one, which has no fixed version upstream.
- **Newer tools** — cosign 3.1.4, osv-scanner 2.6.0, zizmor 1.31.0, ampel 1.3.10, and bnd 0.4.6, on refreshed base images.

These ship as digest-pinned images that wrangle verifies against its own SLSA L3 provenance before running them — there is nothing to configure.

### Building Go on 1.27? The vulnerability check works again

The default `govulncheck` moves from v1.1.4 to **v1.9.0**. The old default crashed on Go 1.27 projects before it could report anything. If you set `govulncheck-version` yourself, move it to v1.9.0 or newer when you move to Go 1.27.

### Publishing Python? Bump one pin

If you copied wrangle's Python example, move `pypa/gh-action-pypi-publish` to **v1.14.3** (the example now does). v1.14.2 and earlier carry advisory [GHSA-5xjx-3w67-w9x9](https://github.com/advisories/GHSA-5xjx-3w67-w9x9), and wrangle's own scan flags the old pin.

### Also in this release

- The GitHub Actions wrangle composes move to current releases, including `astral-sh/setup-uv` v10.1.0, `docker/build-push-action` v7.4.0, and `github/codeql-action` v4.38.2.

### Check the evidence yourself

Every artifact carries a signed attestation you can verify with `gh attestation verify`, `cosign`, or `ampel`, and the producer and consumer policies let you — and anyone downstream — confirm what ran and what it produced. Recipe: [docs/verifying_artifacts.md](https://github.com/TomHennen/wrangle/blob/v0.4.2/docs/verifying_artifacts.md).
